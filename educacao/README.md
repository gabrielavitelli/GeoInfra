# Explorando Ciências — Animações para o Ensino Fundamental

Plataforma web interativa com animações de **Matemática** e **Física** para o Ensino Fundamental I e II (BNCC).

## Como usar

Abra o arquivo `index.html` no navegador ou sirva a pasta com um servidor local:

```bash
cd educacao
python3 -m http.server 8080
```

Acesse: http://localhost:8080
