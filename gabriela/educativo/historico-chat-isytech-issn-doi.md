## 6) O que é OJS (resumo utilizado no chat)

- OJS (Open Journal Systems) é o sistema editorial para:
  - receber submissões,
  - gerenciar revisão por pares,
  - editar/publicar trabalhos,
  - organizar metadados,
  - suportar fluxo para DOI.
